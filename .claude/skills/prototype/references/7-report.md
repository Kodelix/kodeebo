## Phase 7: Generate Prototype Report

Read `.claude/docs/templates/prototype-report.md` to get the report structure.
Fill in every section based on what was observed during this session. Replace all
placeholder text with real observations — no generic filler. Fill the **Shortcuts
taken** list from the Phase 4 cut-list and the **Security / tenancy surprises**
line from the Phase 6 surprise answer (write `none observed` only if the user said
so — never leave it blank).

Ask: "May I write this report to `prototypes/[name]/REPORT.md`, set the status in
`prototypes/[name]/README.md` to concluded with its findings, and add its row to
`prototypes/index.md`?"

If yes, write the files. Then update `prototypes/index.md` (create if it does not
exist) — append one row to the concept prototype table: name, date, path used,
verdict (PROCEED/PIVOT/KILL, or NOT ASSESSED when nobody has used it), and a link
to the REPORT.md. If a PIVOT chain exists (prior PIVOT-NOTE.md in a related
folder), note the chain. This file is the project's complete history of what was
tried and what was learned.
