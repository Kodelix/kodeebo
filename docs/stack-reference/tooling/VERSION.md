## Kotlin — status flags
- **No stable detekt is compatible with Kotlin 2.4.** Options per product: (a) detekt 2.0.0-alpha.6 on Kotlin 2.4.21, an unsupported combination that must be proven by a run; (b) detekt 2.0.0-alpha.6 with the product held at Kotlin 2.4.10, the version it is built on; (c) wait for detekt's move to Kotlin 2.5.0. This is a `cto` decision (ADR), not a reference-file decision.
- **ktlint 1.8.0 is the last stable and is not Kotlin-2.4-ready.** Only the 2.0.0 line parses Kotlin 2.4 syntax, and it exists only as ALPHA-4. A maintainer comment (2026-10-09) says no 1.x backport is planned (Pinterest no longer backs the project) and that 2.0 should not take long: a tier-3 lead on timing, not a date.
- **ktlint docs conflict:** the ktlint `master` branch docs (`documentation/release-latest`) already show 2.0.0 coordinates (`io.github.ktlint.core:ktlint-cli:2.0.0`), while the docs at tag `1.8.0` show `com.pinterest.ktlint:ktlint-cli`. 2.0.0 stable is not on Maven Central. Treat the `master` docs as unreleased.
