## Discrepancies noticed
- **Compose 1.12 minimum AGP**: 9.1.1 (AGP table) vs 9.1.2 (August '26 post) vs 9.2.0 (third-party-reported release-note text; not on the fetched compose-ui 1.12.0 entry). Pin 9.4.x; treat the exact floor as NOT SOURCEABLE.
- **Material 3 Expressive**: earlier third-party summary implied stable availability; official pages show it is still beta-only in 1.5.0.
- **BOM ↔ library rows**: the bom-mapping page is a flattened table; positional matching was used. Treat the material3 value for 2026.09.00 (1.4.0) as unconfirmed by that page.
- **AGP `<release>` metadata** reads `9.5.0-alpha09`, which conflicts with the "latest stable" reading. Stable AGP = 9.4.x per the release-notes pages; the metadata field is not used here.
- **Play**: an unofficial page still describes API 35 as the 2026 requirement; the official Play Console page (API 36 from 2026-08-31) is used.
