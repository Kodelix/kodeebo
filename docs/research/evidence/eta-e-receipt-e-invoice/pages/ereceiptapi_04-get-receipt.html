Get Receipt

API allows taxpayers to retrieve receipt/return receipt source JSON with additional tax authority added metadata.

Get Receipt Details Get receipt details anonymously

Overview

API allows caller to get full details of the Receipt when requested by unique ID assigned to receipt by eInvoicing & eReceipt solution.

Details include original JSON submission and additional ID and validation details, current status added by the tax authority. Because document is submitted in JSON, this API returns receipt information in JSON.

Signature

API is REST based API that takes unique ID of the document as URL parameter and returns document details that were received from the issuer and additional details added after registration and validation of the document in the tax authority.

Signature: GET /api/v1/receipts/{uuid}/raw

Inputs

This API accepts standard eInvoicing & eReceipt API header parameters for authenticated call. The content type parameter can define the expected output format - JSON .

URL parameter Type Description Value example
uuid UUID Unique ID of the document to retrieve. 68e656b251e67e835…

Outputs

Successful Response

API returns HTTP status code 200.

The resulting structure is a single object of type ReceiptExtended.

Error Response

Error situations are reported back by this API through the standard error response.

No custom error codes are provided by this API.

Additional considerations

Receiver of the receipts can retrieve receipts that are in statuses valid only. If receipt exists, and is issued to given receiver, but status is cancelled, not found code is returned.

Issuer of the receipt can retrieve receipt in received and cancelled status.
