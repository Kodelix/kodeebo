 Enhancements and Improvements
 Updated API: Get Recent Documents default maximum number of documents that can be returned is 10,000 documents instead of 100,000 documents. See Additional Considerations section.
 Recommendation to switch to the new Search Documents API which replaces the existing Get Recent Documents API .
 The Search Documents API has various enhanced filters for precise queries and provides access to even quite large result set in a paginated way.
 Released an integration recommended practices to highlight the recommended integration approaches
