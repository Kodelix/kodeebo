Submit Receipt Documents Get Receipt Overview API allows caller to get full details of the receipt when requested by unique ID assigned to the receipt by eReceipt solution, including the detailed validation results and any associated return receipts linked to the sales receipts. Signature API is REST based API that takes unique ID of the receipt as URL parameter and returns receipt details that were received from the issuer and additional details added after registration and validation of the receipt in the tax authority. Signature: GET /api/v1/receipts/{uuid}/details Inputs This API accepts standard eInvoicing & eReceipt API header parameters for authenticated call. URL parameter Type Description Value example uuid String(64) Unique ID of the receipt to retrieve. 68e656b251e67e835… dateTimeIssued DateTime The date and time when the receipt was Issued . 2015-02-13T13:15Z (datetime format would be yyyy-mm-dd and time zone would be UTC.) Document can be either: Receipt - Receipt is the document issued by the taxpayer for the good or service purchased by customer. Return Receipt - Return Receipt is a document issued by the taxpayer for the purchase goods or service that are returned by the customer Return Receipt Without Reference - Return Receipt Without Reference is a document issued by the taxpayer for the purchase goods or service that are returned by the customer for international return receipts or return receipt that are referencing sales receipts that are not captured on the system.. Outputs Successful Response API returns HTTP status code 200 . The resulting structure is a single object of type ReceiptDetails . Error Response Error situations are reported back by this API through the standard error response . No custom error codes are provided by this API. Additional considerations Receiver of the receipts can retrieve receipts that are in statuses valid only. If receipt exists, and is issued to given receiver, but status is cancelled, not found code is returned. Issuer of the receipt can retrieve receipt in valid and cancelled status.
