Nuget export receipts method Search receipts method Overview It will sync all the submitted status receipts which were submitted before. It will fetch all the submitted status receipts. The process of synchronizing receipts will be as follows: • The system will be regularly checking the status from the external submission API. It will capture the status(valid/invalid) and update the local receipts status accordingly. • If submission is invalid, system will get error info and store it locally. • If submission is valid, system will mark those receipts in the local storage as “synchronized”. • If the toolkit is offline, the submission is cached until the internet connection is restored.
