Sync submission method Nuget method's list Overview This method provides the capability to search the receipts stored in the local database giving any of the search parameters or combination of parameters. Receipts will be sorted by receipt issuance date in descending order. Note! • Search functionality is case-insensitive. • Toolkit doesn't change the status of the locally stored receipts due to the search execution. • Toolkit supports the search only for the taxpayer linked with the POS used when the toolkit was initialized.
