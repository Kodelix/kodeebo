QR code method Export receipt method Overview This method will take the single receipt json as a payload. If UUID value is available in the input json then it will validate the UUID with the newly generating UUID and compare it. Valid receipt will be stored in local cache sql lite db receipt’s table and generating QR code will be stored in ReceiptQr table. Toolkit will consider all the new, cancelled status valid receipts for submission. Note! • If Restrict receipt issuance to business buyers flag enabled at admin portal and issuing receipt to the business buyer then it would be rejected. • Valid receipts will be stored with the status 0 (It is the new receipt status).
