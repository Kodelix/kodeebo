OpenJDK Vulnerability Advisory: 2026/08/18

The following vulnerabilities in OpenJDK source code were fixed in this release. The affected versions are 26.0.2, 25.0.4, 21.0.12, 17.0.20, 11.0.32, 8u502, and earlier. Please note that defense-in-depth issues are not assigned CVEs. We recommend that you upgrade as soon as possible.

The current and previous advisories are available for reference.
